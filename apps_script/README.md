# Автоматика цифр: настройка (один раз, ~15 минут)

Как работает: скрипт Google Apps Script читает таблицу эфиров и таблицу бота саморегуляций и по ссылке отдаёт только числа и имена тренеров. Раз в сутки в 23:50 по Москве GitHub забирает эти числа, проверяет и обновляет `data/stats.json`. Если Google не ответил или прислал что-то странное, на сайте остаются вчерашние цифры.

Готовая к вставке копия скрипта, с уже вписанными ID таблиц, лежит у вас на компьютере: `private/stats.gs`. В репозиторий она не попадает. В репозитории лежит `apps_script/stats.gs` с заглушками вместо ID.

## 1. Создать скрипт в Google
1. Откройте https://script.google.com под тем аккаунтом, у которого есть доступ к обеим таблицам, и нажмите **Новый проект**.
2. Назовите проект, например «schedule — цифры».
3. Сотрите всё в `Код.gs` и вставьте содержимое файла `private/stats.gs`. Сохраните (⌘S).

## 2. Проверить
1. Вверху выберите функцию **testStats** и нажмите **Выполнить**.
2. Google попросит разрешение на чтение таблиц. Нажмите **Предоставить доступ** и выберите свой аккаунт. Появится «Приложение не проверено»: нажмите **Дополнительно**, затем **Перейти к проекту** (это ваш собственный скрипт).
3. В журнале появятся числа: слоты, участники, `hours: 51, minutes: 17` и так далее. Имён участников там быть не должно.

## 3. Опубликовать как веб-приложение
1. Нажмите **Начать развертывание → Новое развертывание**.
2. Нажмите на шестерёнку и выберите тип **Веб-приложение**.
3. **Запуск от имени**: «Я». **У кого есть доступ**: «Все».
4. Нажмите **Начать развертывание** и скопируйте **URL веб-приложения**. Он заканчивается на `/exec`.

Доступ «Все» безопасен: по ссылке отдаются только те же цифры, что и так видны на сайте. Ссылку всё равно никуда не публикуйте.

## 4. Отдать ссылку GitHub
1. Откройте https://github.com/psyteeth/schedule/settings/secrets/actions.
2. Нажмите **New repository secret**. Name: `STATS_URL`, Secret: скопированный URL. Нажмите **Add secret**.

## 5. Первый запуск
1. Откройте https://github.com/psyteeth/schedule/actions, слева выберите **Обновить цифры дашборда**.
2. Нажмите **Run workflow → Run workflow**. Через минуту должна быть зелёная галочка и новый коммит «Обновить цифры дашборда».

Дальше всё работает само, каждый день.

## Если что-то поменялось
- **Новый месяц.** Скрипт сам ищет лист «МЕСЯЦ ГОД», например «ДЕКАБРЬ 2026». Лист должен называться именно так.
- **Новый тренер.** Добавьте его в `CONFIG.TRAINERS` и `TRAINER_ORDER` в скрипте Google и в `ALLOWED_TRAINERS` в `scripts/fetch_stats.py`. Пока этого не сделано, задача на GitHub будет падать: это защита от того, чтобы на сайт попало чужое имя.
- **Только студенты в «ч мин».** Поставьте `INCLUDE_TRAINER_SR: false`.
- **Изменили код скрипта.** Нажмите **Развертывание → Управление развертываниями → ✏️ → Версия: новая → Развернуть**. Ссылка останется прежней.
- **Задача на GitHub красная.** Откройте её лог: там написано, что именно не прошло проверку.
